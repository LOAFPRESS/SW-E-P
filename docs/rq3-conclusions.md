# RQ3 的实践结论：在我们手上的数据里是否成立

论文在 RQ3 末尾给出四条实践结论（"简洁的评论更容易被采纳、带代码片段的评论更容易被采纳、手动触发的 action 采纳率更高、hunk 级比 file 级采纳率更高"）。
这份文档不是重新训练模型，而是直接在 Zenodo 包提供的 **3879 条建模集**上算采纳率（`Change_Label`），用来检验这四条结论在我们的数据里是否成立，供 W7–W8 的"复现原结论"一节直接引用。

- 脚本：`scripts/rq3_conclusions.py`（`python scripts/rq3_conclusions.py --json artifacts/rq3/conclusions.json`）
- 数据：`_selected_reviews_with_features/reviews_contains_valid_by_LLM_lda_topics_selected.csv` + `labels/all_reviews_with_LLM_labels.csv`
- 全量采纳率：**973 / 3879 = 25.1%**（与论文 RQ3 的 25.1% 一致，见 DEV-10）
- AI-only 采纳率：**274 / 2990 = 9.2%**（与论文 9.2% 一致）

## 结论 1：简洁的评论更容易被采纳 —— 全量成立，AI-only 不成立

| 评论长度 | 全量 | AI-only |
| --- | --- | --- |
| ≤ 120 字符 | 413/605 = **68.3%** | 7/84 = 8.3% |
| 120–240 字符 | 219/465 = 47.1% | 15/217 = 6.9% |
| 240–480 字符 | 119/640 = 18.6% | 52/547 = 9.5% |
| > 480 字符 | 222/2169 = 10.2% | 200/2142 = 9.3% |

全量上看，结论非常强（68.3% → 10.2%）；但**去掉 Human 之后这个梯度基本消失**（8.3% / 6.9% / 9.5% / 9.3%）。
原因是 Human 评论既短又多被采纳（Human 889 条占 22.9%，采纳率 78.6%），"简洁"实际上主要在区分 Human 与 bot。
这与 SHAP 的第一名特征是 `Is_Human` 相互印证：**在这份数据里"简洁→采纳"更像是"人写的→采纳"。**
报告里应写成"全量成立、但在 AI 评论内部不成立"，而不是直接照抄论文。

## 结论 2：带代码片段的评论更容易被采纳 —— 成立（AI-only 内更明显）

| 条件 | 全量 | AI-only |
| --- | --- | --- |
| 含行内代码 | 429/2425 = 17.7% | 219/2146 = **10.2%** |
| 不含行内代码 | 544/1454 = 37.4% | 55/844 = 6.5% |
| 含多行代码块 | 442/1384 = 31.9% | 162/1070 = **15.1%** |
| 不含多行代码块 | 531/2495 = 21.3% | 112/1920 = 5.8% |

全量上看"含行内代码反而更低"（17.7% vs 37.4%），同样是 Human 混淆（Human 评论很少带行内代码）；
**在 AI 评论内部方向翻转并与论文一致**：含行内代码 10.2% > 6.5%，含多行代码块 15.1% > 5.8%。
多行代码块的效应（+9.3pp）比行内代码（+3.7pp）更大，值得在报告里单独提一句。

## 结论 3：手动触发的 action 采纳率更高 —— 成立

| 触发方式 | 全量 | AI-only |
| --- | --- | --- |
| auto | 259/2886 = 9.0% | 259/2886 = **9.0%** |
| manual | 15/104 = 14.4% | 15/104 = **14.4%** |
| human | 699/889 = 78.6% | — |

manual 比 auto 高 **5.4pp**（14.4% vs 9.0%）。注意 manual 只有 104 条（3.5%），置信区间较宽，
报告里建议写成"方向一致、样本量小"。

## 结论 4：hunk 级比 file 级采纳率更高 —— 成立且差距最大

| 粒度 | 全量 | AI-only |
| --- | --- | --- |
| file-level | 126/2301 = **5.5%** | 126/2301 = 5.5% |
| hunk-level | 148/689 = **21.5%** | 148/689 = 21.5% |
| human | 699/889 = 78.6% | — |

差距 **16.0pp**（21.5% vs 5.5%），是四条里最强的一条；SHAP 里 `Is_File_Level_Action` 排第 3（mean |SHAP| 0.0323）也支持这一点。

## 写报告时的三点提醒

1. **必须先说明分母**：四条结论都是在 3879 条"被 LLM 判为 Valid"的评论上算的，不是 150 条 gold 样本（见 DEV-10）。
2. **Human 混淆要单独点出来**：结论 1 与结论 2 的全量方向都被 Human 拉偏，报告里给出 AI-only 列，避免和论文数字直接对撞。
3. **样本量**：manual 104 条、hunk-level 689 条、file-level 2301 条；manual 的结论要加"样本量小"限定。
